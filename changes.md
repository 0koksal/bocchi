- Map mods from the marketplace no longer crash the game after Apply: LTK Manager reads `.modpkg` natively, but Bocchi converted every package to `.fantome` first, and that conversion kept only WAD chunks — the package's `game_data.yaml`, which holds the map's bin and material edits, was dropped, so the map loaded without them and the game exited. A `.modpkg` now reaches LTK Manager untouched, and the classic cslol path keeps the converter, which now carries such declarations as `META/game_data/<layer>/...`
- A skin that was repaired once is repaired again when the same original is re-downloaded later: the pre-Apply health pass found the earlier report (stored under the original file's hash) and skipped the repair even though the archive on disk was the unrepaired original, so the broken base-skin data was applied and the skin did not show up; the pass now skips only when the archive's own hash equals the repair's output hash
