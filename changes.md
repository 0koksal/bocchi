- "Apply Skin Models to Equipped Skins"  is added. Default skin is no more mandatory , you can select your own skin from client and different skin from bocchi. /example: you own justicar aatrox and can select primordian aatrox so you will see primordian aatrox and everyone sees justicar aatrox.
- Fixed P2P downloads failing when a mod's size was not a multiple of 64 KB.
- Only http(s) links open now, so a `file:` or `ms-msdt:` link from remote data can no longer launch anything.
- Received P2P files stay inside Bocchi's temp folder, so a crafted name cannot overwrite files elsewhere (thanks @shodai.js ).
- The layer picker now works for `.fantome` and `.zip`, not just `.modpkg` (layers are read from `META/info.json`).
- A `.fantome` with a duplicate `META/info.json` (case-only difference) no longer fails Apply, and its preview image shows.
- When several packages target one champion, only the highest-priority equipped appearance is prepared.
- Equipped models are cached: unchanged ones are reused and damaged ones are rebuilt.
